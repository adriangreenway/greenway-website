Before You Start
How This Works
What changed from v1

The v1 Bible was a reference document with checklists. This v2 is a builder. Every pending decision is now an input you can fill out. Locked decisions show as green confirmed badges. As you make choices, live previews update to show what the site will look like. When you're done, hit "Export Build Brief" to generate the complete spec for Claude Code.

How to fill it out

Go section by section. Green sections are already locked and just show what was decided. Amber sections need your input. For copy, you'll see 2 to 3 pre-written options (the top pick is marked "Recommended") plus a field to write your own. For design decisions, click the visual option you prefer. For content like FAQ questions or review quotes, add items to the list. Everything saves to your browser automatically.

Navigation

Click the menu icon in the top left to jump to any section. The green/amber/gray dots show each section's status. The floating percentage in the bottom right tracks overall progress. Use the "Export Build Brief" button at the bottom center whenever you want to generate the output.
